## Storage Clearer 1.0.0 preview

Direct Apple silicon build for macOS 13 or later.

### Install

1. Download `Storage-Clearer-1.0.0-arm64.zip`.
2. Unzip it and move **Storage Clearer.app** to Applications.
3. On first launch, if macOS blocks the unsigned preview, Control-click the app, choose **Open**, then confirm **Open**.

### Notes

- This preview is unsigned and not notarized.
- Storage audits are read-only until you review a refreshed plan and enter its exact approval phrase.
- Docker Desktop and Xcode are optional.
- The SHA-256 checksum is attached to this release.
